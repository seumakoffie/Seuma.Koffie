# ☕ Seuma.Koffie — Authentic Artisanal Aceh Coffee & Brews

Web application modern untuk **Seuma.Koffie** — Menghadirkan kenikmatan seduhan Kopi Sanger khas Aceh, espresso artisanal, serta minuman kekinian dengan layanan pesan antar kilat 15–20 menit di Kota Lhokseumawe dan sekitarnya.

---

## 🌟 Fitur Utama (v5.0 & v6.0)

- **🎨 Modern Luxury UI/UX:** Tema warna Espresso Roasting, Caramel, dan Warm Gold dengan efek glassmorphism dan transisi dinamis.
- **📱 Ultra-Responsive & Zero-Overflow Layout:** Adaptif sempurna di seluruh perangkat (Android, iPhone, iPad, Tablet, Laptop, dan Desktop 4K).
- **🔒 Keamanan Data & Trust Strip:** Dilengkapi proteksi data konsumen menggunakan teknologi Blockchain Ledger terdesentralisasi & End-to-End Encryption (AES-256).
- **🛡️ Anti-Fraud Warning Box:** Info box waspada penipuan resmi Seuma.Koffie untuk keamanan transaksi QRIS dan COD.
- **✨ Onboarding Welcome Ordering Gate:** Dialog selamat datang interaktif dengan tombol pendaftaran akun baru, login, dan opsi jelajah menu.
- **📜 Syarat & Ketentuan Layanan:** Modal persetujuan S&K transparan sebelum pembuatan akun member.
- **🛒 Keranjang & Checkout Real-Time:** Integrasi QRIS Bank Indonesia & COD kilat 15-20 menit.

## 🛠️ Pengembangan Lokal

```bash
# 1. Clone repository
git clone https://github.com/seumakoffie/Seuma.Koffie.git
cd Seuma.Koffie

# 2. Ambil dependensi
flutter pub get

# 3. Jalankan di browser Chrome
flutter run -d chrome
```
